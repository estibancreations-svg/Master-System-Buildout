# MEMORY GEM DEFINITION

A Memory Gem is an exact mirrored archival copy of a complete conversation.

It is not a summary, excerpt, cleaned transcript, outline, interpretation, or selection.

A valid Memory Gem preserves:

- Every user message
- Every assistant response
- Original sequence
- Repeated content
- Corrections
- Disagreements
- Decisions
- Development history
- Final prompted output

Nothing may be trimmed, condensed, reorganized, rewritten, corrected, or silently omitted.

Structured specifications derived from a conversation must be stored separately and must never replace the Memory Gem.
