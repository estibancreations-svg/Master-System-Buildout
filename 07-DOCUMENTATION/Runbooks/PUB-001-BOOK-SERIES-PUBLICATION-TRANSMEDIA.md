# PUB-001 — Book / Series Publication & Transmedia Runbook

**Mode:** Sprint or Full Mission  
**Owner:** Publishing & Media Studio  
**Executive/Operational Oversight:** T.H.E.L.M.A.  
**Creative Authority:** CEO / Author  
**Distribution Interface:** CMGIO  
**Version:** 1.0.0  
**Created:** 2026-08-11

## Mission Trigger

Use when a work or series needs one or more of the following:

- first publication
- republication/revised edition
- cross-book continuity review
- canon extraction
- book-series development
- audiovisual adaptation
- audiobook/podcast adaptation
- trailers/shorts/social derivative content
- coordinated release package

## Required Inputs

- source manuscript(s) or edition(s)
- work/series identity
- known author notes and revisions
- known prior editions
- known rights/provenance records
- target outcome: publish / republish / adapt / audit / combine

If source material is incomplete, mission status becomes `BLOCKED_INPUT` rather than inventing missing canon.

## Phase 0 — Source Integrity & Ingest

**Roles:** Publishing Orchestrator, Rights & Provenance Steward, Edition Manager

Tasks:

1. enumerate all source files/editions
2. assign immutable source references/checksums where possible
3. preserve originals read-only
4. identify missing editions/assets
5. record author/source/ownership metadata
6. classify work as standalone or series

**Gate 0 — Source Integrity**

PASS requires:

- original sources preserved
- active working copy identified
- version ambiguity documented
- missing material explicitly logged

## Phase 1 — Canon & Series Extraction

**Roles:** Canon Keeper, Narratologist, Continuity Editor

Extract/update:

- timeline
- character registry
- relationships/family trees
- locations
- organizations
- rules/world facts
- themes/motifs
- voice pillars
- major events
- foreshadowing
- unresolved/resolved threads
- forbidden retcons
- source references for every material canon fact

For existing series, compare against the current Series Bible.

**Gate 1 — Canon Review**

PASS requires:

- canon extraction coverage is sufficient for the mission
- contradictions are listed, not silently resolved
- uncertain facts are marked uncertain
- sources are traceable

## Phase 2 — Structural / Developmental Review

**Roles:** Narratologist, Developmental Editor, Book Co-Author/Author Support

Review:

- controlling idea/theme
- plot/narrative structure
- pacing/tension
- character arcs
- chapter/scene purpose
- logic and causality
- narrative debts/setup-payoff
- series positioning
- opportunities created by republication

Output:

- developmental assessment
- change proposals
- risk to existing canon
- decisions requiring author input

**Gate 2 — Author Decision**

The author explicitly approves, rejects, or modifies material revision directions.

No AI capability may silently rewrite canon at this gate.

## Phase 3 — Revision

**Roles:** Book Co-Author/Author Support, Developmental Editor, Canon Keeper

Rules:

- preserve author voice
- version every substantial revision
- flag assumptions/evidence gaps
- maintain change log
- update Series Bible only for approved canon changes

Output example:

`BOOK-03 / Revised Edition / Manuscript v6 / Author Review Candidate`

## Phase 4 — Continuity & Independent Quality Review

**Roles:** Continuity Editor, Canon Keeper, Reality Gate, Evidence Collector

Validate:

- timeline consistency
- character facts
- relationship consistency
- voice consistency
- location/world rules
- setup/payoff consistency
- contradictions against other books
- unintended canon drift

**Gate 4 — Continuity Quality**

Default result is `NEEDS WORK` until evidence supports PASS.

## Phase 5 — Editorial Production

**Roles:** Line Editor, Copy Editor, Proofreader, Publishing Production Manager

Perform as appropriate:

- line edit
- copy edit
- spelling/grammar/style consistency
- front/back matter
- chapter formatting
- typography/layout
- accessibility checks
- ebook/print package preparation

Changes after proof stage must trigger targeted re-proof.

## Phase 6 — Rights, Metadata & Release Package

**Roles:** Rights & Provenance Steward, Metadata Manager, Cover/Visual Director

Prepare/verify:

- title/subtitle
- author/contributor data
- edition statement
- descriptions
- categories/keywords
- rights/licensing
- source/asset provenance
- cover package
- identifiers/distributor metadata where applicable

**Gate 6 — Rights & Provenance**

No release if ownership/licensing of required assets is unresolved.

## Phase 7 — Final Release Gate

**Roles:** Reality Gate + Author/CEO

Validate:

- correct manuscript version
- production files match approved edition
- all required gates passed
- remaining limitations disclosed
- release package complete

Decision:

- READY
- NEEDS WORK
- BLOCKED

## Phase 8 — Publication

Publish/distribute using approved channel integrations.

Store:

- release date
- edition/version
- distributor/platform references
- final production artifacts
- release evidence

## Phase 9 — Transmedia Adaptation (Optional)

Create a separate derivative mission or continue under the Full variant.

### Adaptation candidates

- audiobook
- serialized audio
- audio drama
- podcast season/episodes
- long-form video
- episodic video
- book trailer
- character trailer
- scene teaser
- Shorts/Reels/TikTok
- quote cards
- author commentary
- behind-the-book content
- website lore/extras

### Required rule

Every derivative asset references the exact canonical source edition/chapter/scene.

**Adaptation Team** may include:

- Screen Adaptation Writer
- Visual Storyteller
- Storyboard Director
- Audiobook Producer
- Podcast/Audio Strategist
- Short-Form Production Specialist
- Video Optimization Specialist

## Phase 10 — CMGIO Distribution & Growth

Only approved masters/release candidates cross into CMGIO-controlled distribution.

CMGIO may:

- adapt packaging by platform
- build launch campaigns
- create paid/organic distribution plans
- optimize titles/thumbnails/metadata
- schedule staged releases
- measure analytics
- recommend creative iterations

CMGIO may not alter canonical manuscript/story facts without a return handoff to Publishing.

## Phase 11 — Performance & Learning

Record:

- publication performance
- content engagement
- video/audio retention
- audience feedback
- sales/conversions where available
- derivative asset performance
- continuity/editorial issues discovered after release
- recommended next-edition changes

Performance feedback creates proposals, not silent source edits.

## Retry / Escalation

- editorial correction: up to 3 targeted loops before decomposition/escalation
- continuity contradiction: escalate to author when canon cannot be resolved from evidence
- rights conflict: hard block release
- production mismatch: hard block release
- low-confidence factual/source issue: quarantine for human decision

## Completion Criteria

A publishing mission is complete only when:

- final approved edition is versioned and archived
- all required gates have evidence
- release state is recorded
- provenance is complete
- Series Bible/canon is synchronized
- derivative relationships are recorded if created
- post-mission learning is captured
