# Manuscript Format Guide

## Supported source files

- Markdown (`.md`)
- Plain text (`.txt`)
- PDF (`.pdf`)

## Best practices

- use headings for chapters when possible
- separate scene shifts with explicit markers or strong paragraph transitions
- keep character names consistent
- identify unusual spellings or aliases in notes
- include any style or adaptation notes near the beginning of the manuscript package

## PDF guidance

PDFs are supported, but text extraction quality may vary. If the extracted text is ambiguous, the system will request confirmation before storyboarding.

## Parsing targets

The intake stage looks for:

- chapters
- scenes
- characters
- locations
- emotional beats
- dialogue/action transitions
