# Quick Start Guide

## 1. What this package does

The Higgsfield Integration Layer gives VisionWeaver a governed manuscript-to-film workflow:

1. upload manuscript
2. parse scenes, characters, and locations
3. ingest or generate references
4. review storyboards
5. approve production plan
6. generate clips
7. edit final film
8. publish social and publication derivatives

## 2. First manuscript run

1. upload a `.md`, `.txt`, or `.pdf` manuscript
2. complete title, author, genre, target audience, and visual style metadata
3. answer the reference-image prompt for characters, locations, props, and mood boards
4. upload existing images or ask the system to generate missing references with Higgsfield
5. review the returned scene and episode breakdown
6. approve or revise storyboard candidates
7. approve the production plan before movie creation begins

## 3. Expected outputs

- manuscript package
- storyboard package
- production plan
- scene clip library
- final film exports
- distribution and publication package

## 4. Important rule

Do not treat a generated image or clip as approved until the system records the stage approval gate.
