# Troubleshooting Guide

## Common issues

### PDF extraction is incomplete
- keep the original PDF
- review the extracted text snapshot
- supply a cleaner export or manual text correction if needed

### Character visuals drift across scenes
- review the approved reference set
- confirm Soul ID binding or equivalent identity lock
- regenerate only the affected scenes or clips

### A long render stops mid-run
- inspect the job receipt and last completed checkpoint
- resume from the last approved asset set when possible
- avoid deleting the partial run because it is provenance evidence

### A storyboard scene looks wrong
- request a targeted modification instead of regenerating the entire storyboard package
- record the reason for the change so later versions remain auditable
