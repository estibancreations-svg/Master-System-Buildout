# Reference Image Guide

## What to upload

You can upload references for:

- characters
- locations
- props / objects
- wardrobe
- lighting or mood boards
- style references

## Character sheets

Character references work best when they include:

- face clarity
- body type / silhouette
- costume cues
- age indicators
- color palette

## Soul ID setup

When supported, approved character references are bound to a Soul ID or equivalent identity lock to reduce drift across storyboard and movie-generation stages.

## Missing references

If you do not have reference images, the system will pivot into guided Higgsfield generation and preserve the generated reference lineage in the provenance chain.
