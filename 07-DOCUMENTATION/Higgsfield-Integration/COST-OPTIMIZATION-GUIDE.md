# Cost Optimization Guide

## Reduce unnecessary credits

- upload existing references when available
- lock character and location references early
- batch storyboard generations for similar scenes
- regenerate only affected scenes or clips after feedback
- prefer lower-cost models for exploratory passes when quality is sufficient

## Budget checkpoints

Review the estimated budget before movie creation begins. The highest spend typically occurs during multi-take clip generation, so approval gates matter most in Stage 4.

## Watch variance

Track estimated versus actual credits after each stage. Large variance should trigger a planning review before more generations are queued.
