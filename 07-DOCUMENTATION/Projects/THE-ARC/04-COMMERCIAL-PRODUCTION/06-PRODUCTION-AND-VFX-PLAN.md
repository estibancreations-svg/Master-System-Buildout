# THE ARC — Production and VFX Plan v1.0

## Production Strategy
Build the show around a controlled set of reusable environments rather than generating or designing everything from scratch every episode.

## Asset Stack
1. Canonical Master Arc image/video
2. Digital Twin zone map
3. Entity registry
4. Production prompts
5. Set/environment concepts
6. Shot templates
7. VFX rules
8. QA gates

## Reusable Digital Assets
- ARC-01 exterior / interior master
- Axial spine
- Central rings
- Four stabilizing quadrants
- Antenna/spire
- Branch 1 street kit
- Branch 2 civic kit
- Branch 3 aquatic kit
- Branch 4 green/agricultural kit
- Branch 5 technical/service kit
- Shield panel kit
- Green lock kit
- Water deployment kit
- Under-panel ocean kit
- Transit craft kit
- Small vessel traffic kit
- Emergency lighting kit

## Practical Sets
Build limited practical environments that can be extended digitally:
- Core command interior
- Ring maintenance corridor
- Branch 2 civic office/archive
- Branch 5 service deck
- Branch 1 apartment/street frontage
- Branch 3 aquatic control room
- Branch 4 greenhouse/green corridor
- Transit cockpit/interior

## Virtual Production / CG Strategy
Use large-format digital environments for:
- curved city horizon
- ring/spine flythroughs
- exterior Arc views
- under-panel ocean scale
- shield transformation
- water circulation
- branch-to-branch transitions

## AI/Runway/VisionWeaver Role
Use AI generation for:
- concept iteration
- previs
- trailer shots
- mood development
- transition tests
- environmental exploration
- shot design

Do not use AI generation as the only continuity control. The Digital Twin must remain the authority.

## Production Approval Chain
1. Select vessel class
2. Select zone/state
3. Pull entity pack
4. Pull visual references
5. Generate/design asset
6. Run continuity QA
7. Run story QA
8. Run engineering plausibility QA
9. Approve into asset registry

## First Production Goal
Complete a 90-second proof-of-concept trailer using ARC-01.
