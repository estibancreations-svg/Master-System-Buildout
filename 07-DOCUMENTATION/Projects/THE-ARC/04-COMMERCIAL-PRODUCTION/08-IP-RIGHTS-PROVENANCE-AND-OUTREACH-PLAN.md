# THE ARC — IP Rights, Provenance, and Outreach Plan v1.0

## Purpose
Make the project safer to pitch, package, sell, finance or license.

## Rights / Chain-of-Title Checklist
- [ ] Project title log
- [ ] Creator ownership statement
- [ ] Creation date log
- [ ] Prompt and asset provenance log
- [ ] Runway task ID log
- [ ] Source-image/source-video inventory
- [ ] Generated asset approval log
- [ ] Contributor list
- [ ] Work-for-hire agreements for collaborators
- [ ] Composer/sound agreements
- [ ] Voice talent agreements
- [ ] Script registration/copyright review
- [ ] Trademark screening for final title
- [ ] Legal review before commercial submission
- [ ] Pitch-recipient tracking
- [ ] NDA policy
- [ ] Submission-release policy
- [ ] Version history

## Asset Provenance Rule
Every buyer-facing image, video, prompt, deck, treatment and script should be traceable to:
- date
- creator/operator
- tool
- source prompt
- source reference
- task ID / file ID
- approval status
- rights notes
- commercial-use notes

## Outreach Materials
Prepare three versions:
1. **Creative Pitch Deck** — for producers, managers and creative buyers
2. **Investor Package** — for financing and strategic partners
3. **Technical/VFX Package** — for production partners and vendors

Do not broadly send the full package until:
- the pitch deck is clean
- the logline is locked
- chain-of-title packet exists
- asset provenance is organized
- screenplay/treatment version is dated
- outreach tracker is ready
