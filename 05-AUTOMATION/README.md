# Automation

Workflows, APIs, and integrations for system automation.

## Directories

- **n8n-Workflows** - n8n workflow definitions and automations
- **APIs** - API specifications and documentation
- **Integrations** - Third-party integrations and connectors
- **Higgsfield-Integration** - Stage-by-stage automation implementation specifications for manuscript intake, storyboarding, production planning, movie creation, post-production, and distribution
